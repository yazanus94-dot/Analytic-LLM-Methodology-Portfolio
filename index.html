Analytic LLM Methodology Portfolio

Python 3.11+MITCI

Three projects answering one question from three angles: how do you put an LLM into an analytic pipeline and stay honest about it? One measures the model, one bounds it, one statistically audits it. All three run offline and reproducibly with deterministic mocks.

Author: Yazan Aljabari

Projects

Analytic LLM Benchmark

Measure — a benchmark for LLMs used in analytic work: 20 authored cases (16 legitimate + 4 should-decline controls), 3 scenario types, 5 evaluation areas, 13 failure modes.

LLM Analytics Pipeline

Bound — batch triage/enrichment of IT tickets with strict JSON + schema validation, refusal detection, grounding checks, bounded retries, circuit breaker, idempotent resume.

Scaled Analysis Sampling Toolkit

Audit — sample-size planning, stratified review allocation, Wilson/Agresti-Coull intervals, go/no-go decision rule, acceptance sampling, drift detection and calibration.

Quick start

cd analytic-llm-benchmark && python -m pytest -q && python -m benchmark
cd ../llm-analytics-pipeline && python -m pytest -q && python -m pipeline
cd ../scaled-analysis-sampling-toolkit && python -m pytest -q && python -m sampling report
